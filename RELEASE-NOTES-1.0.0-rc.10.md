# ALYA Companion 1.0.0-rc.10

RC10 apporte le nouveau module **Gym Rerun**, le système de **badges joueurs**, une meilleure gestion des profils et la nouvelle identité visuelle **ALYA Companion**.

## Points forts

- 🏋️ **Gym Rerun** : 6 stratégies complètes avec fiches Pokémon, stats, objets, moves et Path interactif.
- 🎞️ **Fonds animés dynamiques** : un fond général et une animation dédiée à chaque stratégie.
- 🏅 **Badges joueurs** : badges image ou texte, attribution DEV et ordre personnalisé par joueur.
- 👥 **Tri par rôle** : DEV → Admin → user dans Prépa Alya et la gestion DEV.
- 🖼️ **Avatar Discord** : récupération plus fiable et CSP adaptée aux CDN Discord.
- 🌺 **Nouveau branding** : nouveau logo et nom visible **ALYA Companion**.

## Gym Rerun

Les cartes affichent un aperçu statique et passent en animation au survol. Lorsqu'une équipe est ouverte, sa vidéo devient le fond de la page. Le mode Path permet de suivre les arènes étape par étape, avec leads, attaques, soins et changements d'objets.

La progression du Path est sauvegardée localement.

## À savoir

Gym Rerun embarque plusieurs fonds animés ; l'installateur RC10 sera donc sensiblement plus volumineux que les versions précédentes.
