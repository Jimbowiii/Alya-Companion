# ALYA Companion 1.0.0-rc.11

RC11 transforme ALYA Companion en un véritable centre de contrôle PokeMMO : gestion communautaire enrichie, événements globaux, agriculture de baies avec timers, raids, bibliothèque de mods, nouveaux onglets web, lecteur Stream configurable et sidebar organisée par catégories.

## Points forts

- **Baies** : plan complet pour 6 personnages, besoins en graines, modes d'arrosage 8h/10h, timers persistants et notifications Windows.
- **Raids** : six raids avec escouades détaillées et plan de combat tour par tour.
- **Mods** : installation directe dans PokeMMO, import local, téléchargements multi-fichiers et mods ALYA embarqués.
- **Événements Dashboard** : annonces globales avec image, couleur, compte à rebours et liens cliquables.
- **Rôle GOUROU** : niveau intermédiaire entre DEV et ADMIN avec permissions sécurisées côté serveur.
- **Web** : Poképédia et Pokébip intégrés.
- **Stream** : page web configurable avec mini-fenêtre toujours au premier plan.
- **Sidebar** : catégories repliables et réordonnables pour garder une navigation claire malgré l'ajout de nombreux modules.

## Mise à jour

La RC11 est distribuée via l'updater intégré d'ALYA Companion. Comme pour les versions précédentes, les fichiers de mise à jour sont signés et la version publiée doit être `1.0.0-rc.11` dans les métadonnées Tauri.
